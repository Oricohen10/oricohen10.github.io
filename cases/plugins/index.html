Four plugins built to replace manual steps in the LUX 2.0 workflow - from token sync to layout scaffolding to icon search.

Built to close the gaps.
No plugin fit what LUX needed.

So we built four. Each one replaced a different manual step in the LUX 2.0 workflow - less friction, more time designing.

Background

LUX 2.0 introduced a three-layer token architecture, a Figma-to-GitHub pipeline, and strict component standards. The existing plugin ecosystem wasn't built for any of it.

Designers were editing JSON files by hand, committing changes manually, and waiting on developers to trigger builds. Every plugin we evaluated either lacked token awareness, required developer handoff, or wasn't designed for a system of this scale. The tools didn't exist, so we built them.

The Pipeline

The goal was a single-click path from Figma to production. A designer updates a token value in Figma Variables, hits Sync in the plugin, and a validated pull request lands on GitHub automatically. TypeScript generation, Storybook rebuild, and deployment all follow without another person involved.

Zero terminal. Designer to GitHub in 60 seconds.

The full chain

Only the first two steps require a human. Everything after the plugin fires is automated.

The Plugins

Each plugin targets one gap. Together they cover the full design-to-production loop without leaving Figma.

01 Token Pipeline
Token Sync

Pushes updated design tokens from Figma directly into the pipeline. One click and tokens.json commits, the GitHub Action fires, and Storybook rebuilds. No developer needed.

02 Layout Scaffolding
Layout Creator

Scaffold a full LUX 2.0 layout in seconds. Generates containers, navigation, and page structure with the correct token bindings already applied - ready to design into, not from scratch.

03 Data Table Generator
Table Creator

Generate data tables with configurable rows, columns, and content. Every output matches the LUX 2.0 Data Table token structure exactly - consistent across every Figma file, without manual assembly.

04 Icon Search
Icon Library Picker

Browse and insert icons from the LUX 2.0 library - 1,281 icons searchable by name, category, or meaning. Inserts directly into your frame with correct sizing and token binding already applied.

Result

The plugins removed four manual steps from the LUX 2.0 design workflow. What used to take 30 minutes of file editing and developer coordination now takes one click. Every plugin ships with the same constraint: it must work without a terminal, without a developer, and without waiting.

Token sync that previously required a developer now runs from within Figma. Layouts that started as blank frames now scaffold in seconds. Icons that lived in a hard-to-search library are now one search away.

What I'd do differently
1

Build shared infrastructure first. Each plugin was built independently, which led to duplicated token logic across four codebases. A shared utility library from day one would have made updates consistent and cut maintenance overhead significantly.

2

Test the plugin UIs with designers earlier. I prioritized workflow logic over interface polish in the first versions. Iterating on the UX after designers had already adapted to the tools required harder conversations about changing something people had built habits around.
