Four plugins built to remove manual steps from the LUX 2.0 workflow - from token sync to layout scaffolding to icon search.

LUX 2.0 introduced a three-layer token architecture, a Figma-to-Storybook pipeline, and strict component standards. The existing plugin ecosystem wasn't built for any of it.

Every plugin we tried either lacked token awareness, didn't integrate with our GitHub pipeline, or required a developer to finish what a designer started. So we built the ones that did the job.

The Pipeline
Zero terminal.
Designer to GitHub in 60 seconds.

Edit a Figma variable, click once in the plugin, and a validated pull request lands on GitHub automatically. No terminal. No build step. No waiting.

01 Token Pipeline
Token Sync

Pushes updated design tokens from Figma directly into the pipeline. One click and tokens.json commits, the GitHub Action fires, and Storybook rebuilds. No developer needed.

02 Layout Scaffolding
Layout Creator

Scaffold a full LUX 2.0 layout in seconds. Generates containers, navigation, and page structure with the correct token bindings already applied - ready to design into, not from scratch.

03 Data Table Generator
Table Creator

Generate data tables with configurable rows, columns, and content. Every output matches the LUX 2.0 Data Table token structure exactly - consistent across every Figma file, without manual assembly.

04 Icon Search
Icon Library Picker

Browse and insert icons from the LUX 2.0 icon library. Search by name, category, or meaning - and insert the right icon directly into your frame with correct sizing and token binding.
